        A table in HTML is used to display data in rows and columns, making it easy to organize and present complex information visually.

Basic Table Structure
An HTML table is created using the < table> tag, with rows defined by < tr>, headers by < th>, and cells by < td>
Firstname Lastname Age
Priya Sharma 24
Arun Singh 32 

    This creates a table with three columns ("Firstname," "Lastname," "Age") and two rows of data.

Important Table Tags
< table>: Starts and ends the table.

< tr>: Defines a table row.

< th>: Defines a header cell; content is bold and centered.

< td>: Defines a data cell.

< caption>: Adds a caption to the table (optional).

< thead>, < tbody>, < tfoot>: Used for table sections, like header, body, and footer for better organization






This structure is helpful for accessibility and styling.

Use Cases
Displaying tabular data (employee lists, product catalogs, schedules).

Organizing information for easy comparison and readability.

HTML tables are foundational for web development, especially when working with data-driven interfaces or reports.
